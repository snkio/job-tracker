## 🛠️ Tech Stack

- React  
- JavaScript  
- Tailwind CSS
    
## 💫 Features

- **Welcome page:** greeting interface
- **Add offer / Edit offer:** modal form allowing you to save details about your applications
- **Delete offer:** remove offer from record
- **Data persistence:** saving offers in localStorage
    

## 🌐 Getting Started
### Installation

```bash
https://github.com/snkio/job-tracker.git
cd job-tracker
npm install
```

### Running locally

```bash
npm run dev
```
